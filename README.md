# 🌿 Tailwind CSS Plant Blog

A responsive and interactive plant blog interface built to strengthen and demonstrate practical **Tailwind CSS** skills through a complete front-end project.

---

## 📌 Overview

**Tailwind CSS Plant Blog** is a front-end project focused on practicing and applying **utility-first styling with Tailwind CSS**.

The interface was designed and developed to explore how Tailwind CSS can be used to create a clean, modern, responsive, and interactive user interface without relying on traditional CSS stylesheets.

The primary goal of this project is to demonstrate the practical application of **Tailwind CSS concepts** within a complete front-end interface, while also using basic JavaScript to add interactive behavior.

## ❤️ Interactive Like System

Each blog card includes an independent like button.

### Default State

The heart appears with:

- White interior
- Black outline

### Liked State

When the user clicks the heart:

- The heart becomes fully red.
- The like counter increases by one.
- The heart slightly scales for visual feedback.

### Unliked State

When the user clicks the heart again:

- The heart returns to a white interior with a black outline.
- The like counter decreases by one.
- The heart returns to its normal size.

Each card maintains its own interaction state independently.
