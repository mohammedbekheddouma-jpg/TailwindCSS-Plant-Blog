# TailwindCSS Plant Blog

A responsive plant blog website built with HTML5, Tailwind CSS, and JavaScript.

## Features

- Responsive blog card layout
- Responsive design with Tailwind CSS
- Flexbox and CSS Grid
- Hover effects and transitions
- Interactive like buttons
- Dynamic like counter
- SVG icons
- Newsletter subscription form
- Focus and placeholder styling

## Technologies

- HTML5
- Tailwind CSS
- JavaScript
