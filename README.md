## 📖 Overview

**Tailwind CSS Plant Blog** is a front-end project created primarily to practice **Tailwind CSS** in a complete, responsive user interface. Instead of focusing on traditional CSS stylesheets, the project applies Tailwind's utility-first approach to structure, style, and refine a modern plant-themed blog experience.

The project combines responsive layouts, reusable card patterns, visual states, typography, spacing, SVG styling, and lightweight JavaScript interactions in one practical interface.

## 🎯 Objectives

- Strengthen practical knowledge of **Tailwind CSS**.
- Build responsive layouts with Tailwind breakpoints.
- Apply a utility-first workflow to real UI components.
- Practice Flexbox and CSS Grid for responsive composition.
- Explore hover, focus, transition, shadow, border, and typography utilities.
- Combine Tailwind CSS with basic JavaScript for interactive UI behavior.

## 🧩 Tailwind CSS Skills Practiced

| Area | Concepts |

| **Layout** | Flexbox, CSS Grid, responsive breakpoints |

| **Typography** | Font size, weight, family, alignment, tracking |
| **Visual Design** | Colors, backgrounds, borders, rounded corners, shadows |

| **Graphics** | SVG sizing and styling |
| **Component Styling** | Utility-first composition and reusable card patterns |

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/mohammedbekheddouma-jpg/TailwindCSS-Plant-Blog.git
cd TailwindCSS-Plant-Blog
```

### Run the project

Open `index.html` in a modern browser.

> **Note:** Tailwind CSS is loaded through the CDN, so an active internet connection is required for the Tailwind styles to load.
