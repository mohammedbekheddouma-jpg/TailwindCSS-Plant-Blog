# 🌿 Tailwind CSS Plant Blog

A responsive plant blog interface built to practice **Tailwind CSS** and utility-first front-end development.

## 📌 Overview

A modern plant-themed blog UI created with **HTML5, Tailwind CSS, and JavaScript**. The main focus is applying Tailwind CSS concepts in a complete responsive interface.

## 🎯 What I Practiced

- Responsive design and breakpoints
- Flexbox and CSS Grid
- Spacing, sizing, and typography
- Colors, borders, rounded corners, and shadows
- Hover, focus, and transition states
- SVG styling
- Utility-first component styling
- Basic JavaScript interactions

## ✨ Features

- 📱 Responsive blog cards
- 🖼️ Image hover effects
- ❤️ Interactive like buttons
- 🔢 Dynamic like counters
- 🎨 SVG icons
- ✉️ Newsletter form
- 🖱️ Hover and focus interactions

## 💻 Technologies

- **HTML5** — structure and semantic markup
- **Tailwind CSS** — utility-first styling and responsive design
- **JavaScript** — interactive likes and counters
- **SVG** — custom icons

## 🚀 Getting Started

```bash
git clone https://github.com/mohammedbekheddouma-jpg/TailwindCSS-Plant-Blog.git
cd TailwindCSS-Plant-Blog
```

Open `index.html` in a modern browser. Tailwind CSS is loaded through the CDN, so an internet connection is required.
