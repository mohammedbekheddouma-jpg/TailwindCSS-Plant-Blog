## 📌 Overview

**Tailwind CSS Plant Blog** is a front-end project focused on practicing **utility-first CSS with Tailwind CSS**. The interface was built from the ground up to explore responsive layouts, reusable card components, visual states, spacing, typography, and interactive UI behavior.

The main purpose of the project is not the blog content itself, but the practical application of **Tailwind CSS concepts in a complete responsive interface**.

## 🎯 Project Goals

- Build a clean and responsive blog interface with Tailwind CSS.
- Practice utility-first styling instead of traditional CSS classes.
- Apply responsive breakpoints for different screen sizes.
- Build reusable and consistent blog card layouts.
- Practice interactive states such as `hover` and `focus`.
- Combine Tailwind CSS with basic JavaScript interactions.

## 🛠️ Tailwind CSS Concepts Practiced

- Responsive breakpoints
- Flexbox
- CSS Grid
- Spacing and sizing utilities
- Typography utilities
- Colors and backgrounds
- Borders and rounded corners
- Shadows
- Hover states
- Focus states
- Transitions
- SVG styling
- Utility-first component styling

## ✨ Features

- 📱 Responsive multi-column blog layout
- 🃏 Reusable blog cards
- 🖼️ Responsive image sizing and hover effects
- ❤️ Interactive like buttons with dynamic like counters
- 🎨 Styled SVG icons
- ✉️ Newsletter subscription section
- 🖱️ Hover and focus interactions
- 🌐 Clean and modern plant-themed UI

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mohammedbekheddouma-jpg/TailwindCSS-Plant-Blog.git
```

### 2. Open the project

Open `index.html` in a modern web browser.

### 3. Internet connection

The project uses the Tailwind CSS CDN, so an internet connection is required for Tailwind CSS to load.
